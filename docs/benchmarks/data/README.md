# Benchmark data

The `prior-*-summary.csv` files transcribe the aggregate values reported by
the earlier private-CA testbed. They are summary data, not raw per-trial
observations; the original raw dataset was not available when this repository
was assembled. Do not use them to infer sample sizes or confidence intervals.

New `pki-sentinel` runs write raw reproduction outputs as
`chaos-<timestamp>.csv`. Commit any dataset used for a public numeric claim.
