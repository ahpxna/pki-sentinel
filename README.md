# pki-sentinel

Internal PKI for SMEs that continuously proves your clients actually reject revoked certificates.

## Status: under construction

This repository is being built out phase by phase per `pki-sentinel-master-plan.md`.
See [`docs/architecture.md`](docs/architecture.md) for the system design.

## Quick start (once Phase 2 lands)

```bash
cp .env.example .env
make up
make status
```
